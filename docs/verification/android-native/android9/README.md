# Android 9 · API 28

APK 20.0.4, React Native nativo. Emulador ARM64, 1536 MB de memoria y navegación de tres botones. Se revisó el login con y sin recorte superior simulado, con resolución compacta 720 × 1560 y densidad 320. La captura estable con recorte usa la resolución original 1080 × 1920, densidad 420.

El retrato carga y el carrusel cambia. En la primera apertura durante el arranque/configuración del emulador se observó una captura sin retrato; al estabilizar el dispositivo y reabrir cargó correctamente. No se modifica la fotografía ni se atribuye el resultado a una corrección de recursos.

Las capturas muestran el fondo del hero hasta el borde superior y el contenido por debajo de los márgenes seguros, sin una franja azul adicional. No se reprodujo exactamente el defecto de la foto del dispositivo físico. La configuración nativa aplica barras transparentes y controla su contraste en versiones anteriores a Android 15.
