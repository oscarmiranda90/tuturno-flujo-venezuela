# Instrucciones del repositorio

## Idioma

Por instrucción expresa de Oscar, la documentación, los comentarios, los mensajes y las instrucciones propias del proyecto se escriben en español neutro. Esta preferencia sustituye la regla anterior de documentación y comentarios en inglés para este repositorio aislado.

Conserva los nombres técnicos de comandos, bibliotecas, archivos, identificadores y contratos de integración cuando cambiarlos rompa referencias o compatibilidad. Mantén intactas las licencias de terceros. La guía del CEO y sus imágenes son la referencia aprobada.

## Verificación

Ejecuta `npm run check:language` cuando cambies textos. `npm run check` comprueba tipos, lenguaje, precios, navegación, conservación del San, audios y ausencia de Expo. Usa `npm run build` para verificar la compilación.

## Alcance

Este repositorio contiene el flujo web y un contenedor Android con WebViewAssetLoader, sin Expo. `npm run android:apk` genera el APK con sus recursos locales. Storybook muestra el mismo flujo publicado mediante el puente de revisión. Las observaciones privadas de Oscar se guardan en su manual separado y no se publican aquí.
